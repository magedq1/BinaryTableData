# BinaryTable Studio — واجهة Wails

[English](README.md) | **العربية**

BinaryTable Studio هي الواجهة الرسومية لمنفذ Go/TinyGo. بُنيت باستخدام
**Wails v2** و**React 19** و**TypeScript** و**Vite** و**Tailwind CSS 4**
وأيقونات **Lucide**. تبقى عمليات البيانات في حزمة `binarytable`، والواجهة طبقة
رفيعة وآمنة فوق ارتباطات Wails.

---

## المزايا

### محرر الجداول

- إنشاء جدول من منشئ مخطط مرئي (`INT`, `LONG`, `DOUBLE`, `STRING`, `RAW`).
- فتح ملفات الجداول الموجودة للقراءة والكتابة.
- شبكة بيانات بترقيم صفحات ورؤوس ثابتة وتنقل مناسب للوحة المفاتيح.
- مفتش خلية بإدخال حسب النوع، تحقق فوري، وتحرير RAW بصيغة hex.
- البحث في أي عمود، الانتقال إلى أول تطابق، وإبراز الصفوف المطابقة.
- مسح خلية أو صف كامل (تعبئة بالأصفار مع الحفاظ على سعة الصفوف).
- تضمين ملف مباشرة في خلية RAW محددة.
- إفلات ملف جدول داخل النافذة لفتحه.

### محرر قوائم البلوبات

- إنشاء قائمة بسعة **max entries** صريحة (حوار الإنشاء يسأل عنها بدل استخدام
  1000 بصمت).
- فتح قائمة موجودة بسعة `0` (كشف تلقائي) أو بقيمة صريحة، بما في ذلك القوائم
  القديمة/الفارغة التي يكون كشف سعتها ملتبساً.
- قراءة قائمة مضغوطة مباشرة عبر تدفق Deflate؛ العرض للقراءة فقط لكن التصدير
  والمعاينة يعملان.
- تضمين عدة ملفات دفعة واحدة عبر منتقي الملفات أو الإفلات.
- تُبث الملفات مباشرة إلى القائمة (`AddReader`)، لذا لا تحتاج البلوبات الكبيرة
  إلى مساحة في الذاكرة.
- معاينة الصور والنصوص والبيانات بصيغة hex.
- تصدير أو استبدال أو حذف بلوب. الاستبدال والحذف يعيدان بناء القائمة
  بطريقة ذرية ويحتفظان بالملف الأصلي حتى تجهز النسخة الجديدة.
- شريط سعة وأحجام كل عنصر.
- القوائم الجديدة تحجز بادئة الفهرس، لذا يمكن استعادة السعة لاحقاً حتى لو كانت
  القائمة فارغة.

### مختبر Deflate

- ضغط الملفات بصيغة الكتل المتوافقة مع Kotlin.
- فك الضغط مع كاش LRU قابل للضبط؛ وهو المكافئ الرسومي لـ
  `DeflateBinaryStreamReader`.
- فحص حجم الكتلة، رأس المتصل، عدد الكتل، الطول الأصلي، ونسبة الضغط.
- **قراءة المحتوى المفكوك كجدول أو قائمة بلوبات دون استخراجه إلى القرص أولاً.**
  كلا العرضين للقراءة فقط ويستخدمان `DeflateReader` كـ `binarytable.Reader`.
- إفلات ملف لفحصه.

### تجربة سطح المكتب

- نظام تصميم Dark OLED بخطي IBM Plex Sans وJetBrains Mono.
- لوحة أوامر (`Ctrl+K`) بتصفية وتنقل بلوحة المفاتيح.
- توجيه الإفلات العام حسب مساحة العمل النشطة.
- حوارات ملفات أصلية، معالجة محلية فقط، بلا تتبع.
- إشعارات، حالات تحميل، وحلقات تركيز واضحة.
- دعم تقليل الحركة وأهداف تفاعل بحد أدنى 44 بكسل.

## المتطلبات

- Go 1.23 أو أحدث
- Wails CLI v2.17 أو أحدث
- Node.js 20+ وnpm
- WebView2 (مثبت افتراضياً على إصدارات Windows الحالية)

تثبيت Wails:

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0
```

---

## التطوير

```bash
cd tinygo/gui
wails dev
```

أول تشغيل يثبت اعتماديات الواجهة. يشغّل `wails dev` خادم Vite مع إعادة تحميل
حرارية ويعيد توليد الارتباطات في `frontend/wailsjs`.

## بناء الإنتاج

```bash
cd tinygo/gui
wails build -clean
```

يُكتب الملف التنفيذي إلى `build/bin/BinaryTableStudio.exe` على Windows.
البناء يضمّن `frontend/dist` ولا يحتاج Node وقت التشغيل.

## الاختبارات

```bash
cd tinygo/gui
go test ./...

cd frontend
npm run build
```

تغطي اختبارات الخلفية تحرير الجداول، البحث، إضافة/استبدال/حذف البلوبات،
استنتاج السعة، ضغط وفك ضغط Deflate، والحماية من الاستبدال غير المقصود.

## سلوك البيانات

- `Create table` يحجز بالضبط `schema + rows × rowSize` بايت، ويقتطع ملفاً
  موجوداً فقط عند تفعيل **Overwrite**.
- `SetString` يصفّر بقية العمود.
- تحرير RAW بصيغة hex يقبل المسافات وبادئة `0x` الاختيارية.
- تضمين ملف في خلية RAW يفشل إذا كان أكبر من العمود.
- إزاحات `BinaryList` ذات 32-بت، لذا الحد العملي نحو 2 GiB.
- أسماء الملفات ليست جزءاً من صيغة Kotlin؛ تعرض الواجهة الفهارس وأسماء تصدير
  مولدة.
- القائمة الجديدة تكتب `realSize = 0` وتحجز `100 + maxEntries × 4` بايت.
  يستخدم `GuessListCapacity` تلك البادئة أو أول إزاحة بيانات لاستعادة السعة
  لاحقاً.
- عروض الجدول/القائمة المضغوطة تُفك عند الطلب وهي للقراءة فقط. استخدم
  `deflate unpack` (CLI) أو نموذج فك الضغط لإنشاء نسخة قابلة للتحرير.

## البنية

```text
gui/
├── app.go                 تطبيق Wails والحوارات وجلسات الملفات
├── table_service.go       DTOs وعمليات الجداول
├── list_service.go        DTOs وإعادة بناء/حذف قوائم البلوبات
├── deflate_service.go     ضغط/فك ضغط/فحص Deflate
├── main.go                خيارات Wails والتضمين
├── frontend/
│   ├── src/App.tsx        هيكل مساحات العمل والإجراءات
│   ├── src/components/    الجداول والقوائم وDeflate والحوارات
│   ├── src/lib/api.ts     غلاف TypeScript للارتباطات
│   └── src/style.css      رموز التصميم والأنماط الأساسية
└── build/                 أصول تغليف Wails
```

لا تلمس الواجهة الملفات مباشرة. كل عملية تمر عبر ارتباط Wails يستخدم نفس حزمة
`binarytable` التي يستخدمها CLI والمكتبة.

## نظام التصميم

مبني على توصية UI/UX Pro Max لأداة مطورين:

- النمط: Dark OLED، تباين عالٍ، إضاءة منخفضة.
- السطح الأساسي: `#0F172A`، البطاقات: `#1B2336`، الحدود: `#334155`.
- اللون المميز: `#22C55E`.
- الخطوط: IBM Plex Sans للواجهة، JetBrains Mono للقيم والمخطط.
- التأثيرات: توهج محدود، حلقات تركيز واضحة، بلا رموز تعبيرية.
